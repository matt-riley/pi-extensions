## Playbook: session pickup

Copy these steps into your todo list before task-specific items; a step you skip stays with `skip: <reason>`.

1. Read the handoff first (`/handoff` output, or the note the user points at), then `/recall` for the topic.
2. The prior trail is input, not work to redo. Do not repeat investigation the handoff settled unless a claim fails a check.
3. Verify inherited claims on the real artifact: the branch, `git status`, the failing command, the open PR. Note any that no longer hold.
4. Restate in a few lines where the work stands, what is done, and the first action on resume.
5. Start with that first action; do not reopen settled decisions without new evidence.
6. Report what you verified, what had drifted, and what you did next.
